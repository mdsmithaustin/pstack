# Recover after compaction or truncation

Read this reference after a known compaction, context summary, or truncation notice, before the next governed action.

After a known compaction, context summary, or truncation notice, read this entry on its own before the next governed action. Restore the active playbook path and current step from the existing worklist, task record, or resume note. Then read and apply [task triggers](task-triggers.md), the active playbook, and its required current-step references one governing file per outer tool response, or in verified bounded chunks. Require complete returned guidance before any governed action. If a return is shortened or reports truncation, read the missing content first. A read command, a process exit, or a remembered summary does not establish complete content. Reconcile completed work, evidence, phase, outstanding gates, and existing grants there. Continue the same task without a new human pause or repeated work. Preserve required watcher and verification checks. A remembered green summary does not replace them.

If governing guidance is unavailable, report the exact missing file. Withhold only actions whose prerequisites you cannot establish. Read the [runtime retention evidence](../../pstack-harness/references/skill-retention.md) when runtime retention or restoration affects a decision.
