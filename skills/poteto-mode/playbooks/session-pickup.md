### Session pickup

**You own the resume point. Read the prior trail, don't redo it.**

1. Locate the prior trail. A local transcript in this workspace's session store (locate it per the **pstack-harness** skill. Do not read other workspaces' stores, that crosses workspace boundaries and reads private chats from unrelated projects), a cloud-agent URL, or a pushed branch. Read the metadata overview and last messages first, then scan back for the decision points. Parse a long transcript in a subagent and keep the reduced timeline in the main thread (the **principle-guard-the-context-window** skill).
2. Reconstruct operational state. The branch and worktree, what already landed (`git log`, `git diff` against the base), the open todos, the decisions made. The prior trail records completed work and decisions. Restore delegation roles per [Preserve roles across handoffs](../../pstack-harness/SKILL.md#preserve-roles-across-handoffs). For an existing orch workflow, read `orch attempt list` and `orch inbox receipts`, then reconcile `orch inbox drain --receipt` through per-event `orch inbox ack` decisions per the [orch reference](../scripts/orch/README.md). An empty drain returns `null`. Store reads replay unfinished direct write intents and acknowledgment decisions under its lock. Keep each report's saved binding and actual head for publication. Reconcile unknown superseded attempts when a known disposition can be recorded with `orch attempt finish`. Compare the recorded native or CLI observation against runtime and artifact evidence. Missing observation leaves the attempt uncertain. Keep saved role, panel arm, and paired resolution context from the same attempt. Keep known null separate from unknown absence. A replacement resolves that role and arm per [Preserve roles across handoffs](../../pstack-harness/SKILL.md#preserve-roles-across-handoffs), like any other spawn. Replace a slot only with its current predecessor id, and record the harness, model, and effort that will run it before dispatch. Preserve existing retries and permissions. Resist the bias to re-derive completed work.
3. Diff done vs pending. Compare what shipped against what was planned, name the resume point, do not re-run the prior repro or redo completed work. A "let me verify from scratch" pass means you're treating the trail as untrustworthy when it's authoritative.
4. Route the remaining work to the matching playbook and pick the verdict: continue the execution, ship a finished recommendation, ratify or override a prior conclusion, or postmortem a failed run. The pickup playbook ends here. The routed playbook owns the rest.
5. Verify the inherited claims against the original goal on the real artifact (the **principle-prove-it-works** skill). A passing prior self-report is not the proof.

**Reply:** where the prior agent stopped, what you inherited vs redid (ideally nothing redone), the resume point, and the outcome.
