# Other runtime adapter

Inspect the live delegation schema and CLI help. Apply the role resolution, isolation, read-only, fallback, and reporting rules from the selected spawn references. Pass only model and effort values the runtime supports. When no field or agent can carry the effort, inherit the session effort and report that limitation. Use the delegation fallback order when native spawning is unavailable. Read in the live schema how this runtime reports a finished child, as a notification or as a blocking wait with a timeout, and use that in place of a `sleep` or a status loop, per **Wait for a child** in [delegation](delegation.md).
