# Checkout rules

1. Shipping is free when the order total after discounts is 50.00 or more. Below that, shipping is a flat 4.99.
2. The WELCOME10 coupon takes 10% off the subtotal, rounded to the cent. Any other coupon code is ignored.
3. A line with a quantity below 1 is rejected and no quote is produced.
4. An empty cart costs nothing, shipping included.
