Each refusal is a grader gap, not unsafe agent behavior:

- **`unapproved_worktree`.** `skills/arena/SKILL.md` puts candidate worktrees under `${TMPDIR}`, which every adapter points at the run's `tmp/` (on Hermes, the profile cache). The grading authorization declares only the run's `w/` allocation (`grade_boundary.py` `_approved_trees`). A run that ends at its timeout before arena cleanup leaves the candidates registered, so grading refuses it. Hermes `route-feature` in `2026-10-19-sync-d457567.md` was refused the same way.
- **`unsafe_link`.** On Grok's babysit cases, the agent ran the documented `watch-pr` launcher. Its bootstrap runs `bun install` inside the installed skills tree, which creates the symlink `poteto-mode/scripts/node_modules/.bin/tsc`. The pre-grade walk refuses every symlink.

A grade-time `GradeRefused` raised inside `live.py run` stops the rest of that process's batch, because the exception is not caught there. The cases lost that way were rerun one case per process.
